One funny, near-plausible excuse line for skipping work during GTA 6 launch week: a council damp survey you can't afford to miss, because missing the slot means going back to the bottom of the waiting list until February. A tired manager has heard every excuse twice — this one hides behind the dullest, most specific bureaucratic detail it can find. No setup, no explanation, no signature; just the text, sent in a hurry.

## Run it

```sh
node main.ts
```

The program prints the excuse to stdout and writes it (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
